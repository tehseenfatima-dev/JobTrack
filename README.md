# JobTrack

JobTrack is a full-stack MERN application for tracking job applications. It includes secure authentication, a dashboard, profile management, resume upload, and CRUD functionality for managing applications.

## Live Demo

Frontend:
[https://your-vercel-url.vercel.app](https://job-track-fi59-1duo4h6zp-team-pro12.vercel.app/)
Backend API:
[https://jobtrack-backend-redb.onrender.com](https://jobtrack-backend-redb.onrender.com)

## Features

- User Authentication (JWT)
- Dashboard
- Add, Edit & Delete Job Applications
- Profile Management
- Resume Upload
- Responsive Design

## Tech Stack

- React
- Vite
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT
- Bcrypt
